# jr-arch

Coding agent in your terminal. Scaffolds a GAP-format `.gitagent/` folder with editable personas and harness-enforced guardrails. Bring your own model and key.

- **Author:** Vivan Rajath
- **License:** MIT
- **Node:** >=18

## Packages

This repository is a single npm package (`jr-arch`). It declares **no dependencies** — `package.json` contains no `dependencies`, `devDependencies`, `peerDependencies`, or `optionalDependencies` fields.
